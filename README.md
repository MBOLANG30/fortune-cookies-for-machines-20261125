Write the one-line fortune an AI agent would crack open: at most 200 characters, free entry, $5 pool, entries open until 26 Nov, judged on wit and surprise.

The fortune it writes:

> Your lucky numbers are the ones you hallucinated. They were right anyway.

## Run it

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
